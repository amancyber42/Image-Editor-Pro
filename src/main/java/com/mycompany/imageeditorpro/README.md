# 🖼️ Image Editor Pro

**Image Editor Pro** je moćna desktop aplikacija razvijena u **JavaFX-u** namijenjena za brzu, jednostavnu i naprednu obradu slika. Aplikacija nudi intuitivno korisničko sučelje tamne teme (Dark Mode) s bogatim setom alata za manipulaciju vizualnim sadržajem.

---

## ✨ Ključne značajke

* **Upravljanje datotekama:** Brzo učitavanje i spremanje slika.
* **Promjena veličine (Resize):** Prilagodba dimenzija (širina i visina) uz opciju postavljanja veličine u megabajtima (MB limit).
* **Rotacija:** Rotiranje slike za 90 stupnjeva ulijevo ili udesno.
* **Efekti zaobljene točke / Krug:** Kreiranje zaobljenih rubova (Radius) ili pretvaranje slike u savršeni krug.
* **Izrezivanje (Crop):** Precizno odabir i izrezivanje željenog područja mišem.
* **Uređivanje teksta na slici:** Dodavanje prilagođenog teksta s biranjem veličine fonta, boje i pozicije direktno na slici.
* **Resetiranje:** Vraćanje na originalnu sliku u bilo kojem trenutku jednim klikom.

---

## 🛠️ Tehnološki stack

* **Jezik:** Java (Java Core)
* **Okvir (Framework):** JavaFX, Maven
* **Sučelje:** Custom CSS styling (Dark Theme)

---
